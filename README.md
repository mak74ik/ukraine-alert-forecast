**Зручна та автономна система моніторингу повітряних тривог, радару загроз і прогнозування небезпеки по всій Україні на 24 години вперед.**

Працює повністю самостійно, швидко та безкоштовно. Не потребує жодних реєстрацій, логінів чи платних підписок.

---

## 🌟 Чим корисна ця програма

* 🔴 **Точна карта тривог у реальному часі**:
  * Відображає реальний статус тривог по областях, окремих районах та містах.
  * Якщо тривога оголошена лише в частині області (наприклад, у Білій Церкві чи Фастові), на мапі підсвічується саме той район, де є небезпека, а не вся область.
  * Окремо та коректно відображається статус для **міста Київ**.

* 🎨 **Зрозуміле колірне розділення загроз**:
  * 🟡 **Жовтий рівень** — загроза ударних дронів (Shahed/Герань).
  * 🔴 **Червоний рівень** — ракетна небезпека або загроза балістики.
  * 🟠 **Помаранчевий рівень** — загроза керованих авіабомб (КАБ) чи тактичної авіації.
  * 🟢 **Зелений колір** — у вашому районі все спокійно.

* 🎯 **Живий радар повітряного простору**:
  * Відображає помічені безпілотники та цілі, напрямок їхнього польоту (курс) та прогнозований вектор руху на найближчі 15 хвилин.

* ⏱️ **Шкала ймовірності тривоги (Таймлайн на 24 години)**:
  * Дозволяє подивитися історію за останні години та оцінити ймовірність тривог наперед, щоб планувати справи та дорогу.

* 📍 **Персональний вибір вашого регіону**:
  * При вході можна вказати свою область і район — у верхній панелі завжди буде видно статус безпеки саме біля вашого дому.
  * Локацію легко змінити в будь-який момент у шапці сайту.

* 🛰️ **Приємний та сучасний вигляд**:
  * Високоякісна супутникова мапа або м'яка темна тема для вечірнього часу.
  * Звукове сповіщення про зміну обстановки.
  * Швидка та плавна робота без підвисань на комп'ютері чи телефоні.

## 🚀 Як користуватися та запустити

### 📦 Варіант 1: Завантажити готову програму (в один клік)
Перейдіть у розділ **[Релізи на GitHub](https://github.com/mak74ik/ukraine-alert-forecast/releases)** та оберіть версію для вашого пристрою:
* 📱 **Android**: завантажте `.apk` файл для встановлення на телефон (з нативними сповіщеннями про тривогу та вібрацією).
* 🍏 **macOS**: завантажте файл `.dmg`, відкрийте його та перетягніть програму в папку «Програми».
* 🪟 **Windows**: завантажте `.exe` або `.zip` та запустіть файл.
* 🐧 **Linux**: завантажте архів `.tar.gz` та запустіть виконуваний файл.

---

### 💻 Варіант 2: Запуск із вихідного коду

Якщо ви хочете запустити проєкт через командний рядок:

```bash
# 1. Завантажте проєкт
git clone https://github.com/mak74ik/ukraine-alert-forecast.git
cd ukraine-alert-forecast

# 2. Запустіть скрипт автоматичного старту
./run.sh
```

Або стандартними командами Python:

```bash
python3 -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Після запуску відкрийте у будь-якому браузері: **[http://localhost:8080](http://localhost:8080)**.

---

### 🐳 Варіант 3: Запуск через Docker

```bash
docker compose up --build
```
Відкрийте у браузері: `http://localhost:8080`.
