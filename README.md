**Повністю автономна веб-система моніторингу повітряних загроз та прогнозування тривог в Україні на 24 години вперед.**

Працює **100% локально та автономно**: без використання платних хмарних нейромереж, без сторонніх платних API та без необхідності авторизації через Telegram. Будь-яка людина може запустити проєкт в 1 клік на комп'ютері або сервері.

---

## ✨ Основні можливості (Key Features)

1. **🔴 100% точний статус сирен у реальному часі (Ground-Truth Telemetry)**:
   - Інтеграція з відкритими дзеркалами телеметрії сирен (`alerts.in.ua`, `map.ukrainealarm.com`, `ubilling`).
   - Чітке розмежування: області з активною тривогою — **яскраві червоні**, спокійні області — **зелені**, окреме незалежне відображення для **м. Київ (`UA-30`)**.

2. **🎯 Векторний радар повітряних цілей (Neptun Live Radar Mode)**:
   - Відстеження Shahed-136, крилатих ракет, балістики та літаків прямо на мапі з анімацією радіолокаційного імпульсу.
   - Динамічний розрахунок курсів, швидкості (км/год) та векторних стрілок підльоту на 15 хвилин вперед.

3. **📍 Локалізація по 100+ містах та районах (Sub-Regional Hotspots)**:
   - Система розрізняє загальну тривогу по області та локальні загрози окремим містам (наприклад, *Біла Церква, Васильків, Фастів, Нікополь, Павлоград, Чугуїв, Старокостянтинів, Ізмаїл тощо*).
   - Візуалізація точкових пульсуючих маркерів над містами під загрозою.

4. **📈 Поминутна шкала ймовірності тривоги (Native Canvas Timeline Engine)**:
   - Розрахунок ймовірності тривоги на 24 години вперед на основі фізико-кінематичних моделей та добових патернів.
   - Інтерактивний курсор із підказками часу та типу загрози.

5. **📡 Мульти-мережа з 26 відкритих джерел моніторингу**:
   - Автоматичний парсинг офіційних та перевірених джерел: *Повітряні Сили ЗСУ, Оповіщення України, ДСНС, Генштаб ЗСУ, Николаевский Ванёк, Радар Інфо, єРадар, Військовий Монітор, Оперативний ЗСУ та регіональні канали*.

6. **🇺🇦 Кинематографічна заставка з 3D-прапором**:
   - Ефект шовкового прапора України та радіальний круговий перехід при вході.

## 🚀 Швидкий запуск в 1 клік (Quick Start)

### Варіант 1: Запуск через Bash-скрипт (Linux / macOS)
```bash
git clone https://github.com/YOUR_USERNAME/ukraine-alert-forecast.git
cd ukraine-alert-forecast
./run.sh
```

### Варіант 2: Запуск вручну (Python 3.9+)
```bash
# 1. Створіть віртуальне середовище
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# 2. Встановіть залежності
pip install -r requirements.txt

# 3. Запустіть додаток
python main.py
```

Після запуску відкрийте у браузері: **[http://localhost:8080](http://localhost:8080)**

---

## 🐳 Запуск через Docker (Docker & Docker Compose)

```bash
docker compose up --build
```
Додаток буде доступний за адресою `http://localhost:8080`.

## 🏗️ Архітектура проєкту (Architecture)

```
ukraine-alert-forecast/
├── app/
│   ├── api/
│   │   ├── routes.py         # REST ендпоінти (/overview, /forecast, /radar, /logs)
│   │   └── ws.py             # WebSocket менеджер реального часу
│   ├── collector/
│   │   ├── open_monitor.py   # Збір даних із 26 каналів + телеметрія сирен
│   │   ├── parser.py         # Локальний regex/NLP парсер загроз
│   │   └── threat_types.py   # Класифікація загроз (Shahed, MiG, Балістика, КАБ)
│   ├── data/
│   │   ├── cities.py         # База 100+ міст та районів з GPS-координатами
│   │   ├── regions.py        # Дані 25 областей + м. Київ
│   │   ├── sources.py        # Реєстр 26 відкритих джерел моніторингу
│   │   └── seed_history.py   # Добові статистичні матриці ризиків
│   ├── engine/
│   │   ├── forecaster.py     # Математичний движок 24г прогнозування
│   │   ├── radar_targets.py  # Генератор векторних цілей радара (Neptun-style)
│   │   └── trajectory.py     # Кінематика підльоту та просторові ETA
│   ├── static/
│   │   ├── index.html        # Чистий веб-інтерфейс (Tailwind + Leaflet)
│   │   ├── app.js            # Canvas Timeline + інтерактивний Leaflet контролер
│   │   └── ukraine_geojson.js# Офіційні OSM геоконтури областей
│   ├── database.py           # Потокобезпечна база SQLite
│   └── main.py               # FastAPI додаток
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
├── run.sh
├── main.py                   # Точка входу в 1 команду
└── README.md
```
